# NOCL

JAX implementation for the NeurIPS 2026 paper **Neural Operator-based Curriculum
Learning for Physics-Informed Neural Networks**.

This repository contains the NOCL code for the Convection and rebuttal
reaction–diffusion experiments. Training points and reference solutions are
generated by the code.

## Installation

Create or activate a Python environment, then install this package:

```bash
pip install -e .
```

For NVIDIA CUDA 12 runs, install the pinned GPU dependencies:

```bash
pip install -e '.[cuda12]'
```

The experiments use Python 3.12 and JAX 0.5.0. Full training is intended for a GPU.

## Repository Layout

```text
nocl_minimal/         Core model, PDE, curriculum and training utilities
experiments/          Experiment entry points
experiments/configs/  Experiment configurations
experiments/records/  RD protocol and reference records
```

## Run Convection

Run the Convection configuration:

```bash
python -m experiments.run \
  --config experiments/configs/convection.json \
  --gpu 0 --output results/convection/seed42
```

## Run Reaction–Diffusion

Run the rebuttal RD configuration:

```bash
python -m experiments.run \
  --config experiments/configs/rd.json \
  --gpu 0 --output results/rd/seed42
```

This experiment uses a sine initial condition and zero Dirichlet boundaries.
The protocol is documented in `experiments/records/rd_protocol.json`.

For either experiment, use `--gpu` to select a physical GPU, `--seed` to change
the random seed, and `--smoke` for a short functionality check.

## Outputs

Use `--output` to choose a new directory for each run. Training writes metrics
and PINN checkpoints to that directory. Add `--save-operator` to also save the
final FNO weights.

After training, evaluate the saved PINNs and generate field plots:

```bash
for problem in convection rd; do
  python -m experiments.evaluate results/$problem/seed42 --gpu 0 --all-levels
  python -m experiments.plot results/$problem/seed42 --output results/$problem/nocl.pdf
done
```

Evaluation regenerates the reference solution and saves prediction arrays for
plotting. Use the same accelerator backend as training for checkpoint evaluation.
Generated outputs in `results/` are ignored by Git.
